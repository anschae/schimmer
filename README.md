# Schimmer

Schimmer is an atmospheric reverb plugin (VST3 for macOS and Windows, AU for macOS) by anschae.
It is built for huge, dreamy, "larger than life" spaces rather than realistic rooms: pads, drones,
ambient guitar, synths and textures, with shimmer (pitch shifting in the feedback loop), grains,
a tempo-synced delay in front of the reverb, ducking and a tail-reset button.

**Status: in development.** Builds come from GitHub Actions (see the Actions tab).
